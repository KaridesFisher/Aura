Playback libraries
------------------
libmpv and its transitive media libraries are from the official IINA v1.5.0
universal macOS release. The IINA application executable, interface, branding,
and updater are not part of Aura. Only redistributable media dylibs are used.

Distribution artifact:
https://github.com/iina/iina/releases/tag/v1.5.0
SHA-256 of IINA.v1.5.0.dmg:
8fad50479b10e09645053457cec46bd53d054ced2242cfe68f74586735a20dc7

Upstream sources and build information:
https://github.com/iina/iina
https://github.com/iina/mpv
https://github.com/mpv-player/mpv
https://github.com/FFmpeg/FFmpeg
https://github.com/iina/iina/wiki

The dependency set includes FFmpeg, libass, libplacebo, libarchive, dav1d,
SVT-AV1, fontconfig, FreeType, FriBidi, HarfBuzz, libbluray, libudfread, libjxl,
libjpeg, Little CMS, LuaJIT, MuJS, Ogg/Vorbis, libwebp, libsoxr, libspeex,
Rubber Band, uchardet, unibreak, zimg, zstd, Brotli and lz4. Each library
retains its own upstream license. Relevant license families include GPL,
LGPL, BSD, MIT and ISC. The bundled playback build is treated as GPL-compatible.
Publishing a binary release requires preserving upstream notices and providing
the corresponding source and build materials required by those licenses.

The C adapter uses mpv's stable public ABI. Public API documentation:
https://github.com/mpv-player/mpv/tree/master/include/mpv

Service integration
-------------------
OpenSubtitles.com REST API is a separately operated service. Users provide
their own API key/account. No service credentials are shipped in the app.
https://opensubtitles.tawk.help/article/getting-started
https://opensubtitles.stoplight.io/docs/opensubtitles-api

Aura is independent of UHF and uses its own name, icon, layout and source code.
